## How to Run

1. Clone or download this repository.
2. Open the project in Jupyter Notebook or VS Code.
3. Navigate to the required PPT folder.
4. Open the activity or demonstration notebook.
5. Install the required Python libraries if they are not already installed.
6. Run the notebook cells sequentially.

**Note:** The PPT 5 activity notebook uses KaggleHub to download its dataset automatically when a local CSV file is not available. Internet access is required for that download.
